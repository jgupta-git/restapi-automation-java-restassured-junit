Advanced Techniques

Data-Table-Driven Assertions REUSABLE

One step definition drives all assertions from a Cucumber DataTable. Supports 10 matchers.

# Feature file
And the response should match:
  | field  | matcher      | value |
  | id     | notNull      |       |
  | title  | notEmpty     |       |
  | price  | greaterThan  | 0     |
  | rating | between      | 0,5   |
  | tags   | notEmptyList |       |

# Matchers available:
# notNull, notEmpty, notEmptyList,
# greaterThan, between, equalTo,
# equalToInt, listSize,
# everyItemNotNull, everyItemNull,
# everyItemEquals

Response Spec DRY

Reusable response specification for standard DummyJSON endpoints.

ResponseSpecification SPEC =
  new ResponseSpecBuilder()
    .expectStatusCode(200)
    .expectContentType("application/json")
    .expectBody("products", notNullValue())
    .expectBody("total", greaterThan(0))
    .build();

// Usage in step
CommonApiSteps.getResponse().then()
  .spec(SPEC);

Key Code Patterns

Content-Type Fix WORKAROUND

AutomationExercise returns JSON with text/html content type. REST Assured tries XML parser.

// In Hooks.java @Before
RestAssured.defaultParser = Parser.JSON;
RestAssured.registerParser(
  "text/html", Parser.JSON);

// Response filter override
((RestAssuredResponseImpl) response)
  .setContentType("application/json");

JWT Token Flow DUMMYJSON

Login returns accessToken + refreshToken. Use Bearer header for protected endpoints.

// Login → extract tokens
accessToken = response.jsonPath()
  .getString("accessToken");
refreshToken = response.jsonPath()
  .getString("refreshToken");

// Use in request
.header("Authorization",
  "Bearer " + accessToken)

Response Logging REPORT

@AfterStep attaches API response body to Cucumber HTML reports.

@AfterStep
public void logResponseToReport(
    Scenario scenario) {
  if (CommonApiSteps.needsLogging()) {
    Response r = CommonApiSteps
      .getResponse();
    String out = "HTTP "
      + r.statusCode() + "\n"
      + r.asPrettyString();
    scenario.attach(out.getBytes(),
      "text/plain", "API Response");
    CommonApiSteps.markLogged();
  }
}
